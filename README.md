# 💊 Pharmaceutical Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes pharmaceutical sales data to understand business
performance and support data-driven decision-making. A synthetic dataset
representing sales across products, regions, customers, and sales
representatives was used to simulate a real business scenario.

The workflow includes data cleaning and exploratory data analysis (EDA)
in Python, followed by the development of an interactive Power BI
dashboard.

------------------------------------------------------------------------

## ❗ Business Problem

Large volumes of sales data make it difficult to monitor performance,
identify trends, and make timely business decisions using manual
reports.

## ✅ Solution

Built an interactive Power BI dashboard that helps users:

-   Monitor Total Sales, Profit, and Profit Margin
-   Track Monthly Sales Trends
-   Analyze Product Categories and Top Products
-   Evaluate Sales Representative Performance
-   Compare Regional Performance
-   Understand Customer Distribution
-   Monitor Payment Status
-   Identify Top Customers

4.  Exported the cleaned dataset.
